# gcc vs native

Generated by `tool/bench.dart`. gcc = `tools/imcu/shader.py` -> C -> ae32000-elf-gcc -O2 (Wine);
native = this compiler, exact (bit-identical results) and `--fast` (overflow wraps).
Cycles per call from the emulator's device-fitted model, mean over 60 realistic inputs
(pixel x/y, u/v in [0,1), t < 600 s, knobs < 4); every build's outputs were checked against
the reference. The model is within ~5% of the device for native code and reads gcc's
loop-heavy code 5-10% high; the device rows at the end are measured.
